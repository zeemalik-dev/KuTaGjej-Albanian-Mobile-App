# KuTaGjej

KuTaGjej is an Albanian classifieds and services platform, available on the web and as a mobile app. It helps people discover listings across Albania, connect with sellers and service providers, and manage their own listings.

## What you can do

- Browse listings for property, cars, marketplace items, jobs, businesses, and professionals
- Search and filter listings by city and category
- View listing details and contact sellers
- Sign in, manage your profile and listings, and access your messages

## Apps and website

- Website: [kutagjej.al](https://www.kutagjej.al/)
- iOS app: [KuTaGjej on the App Store](https://apps.apple.com/al/app/kutagjej/id6816097736)

## Built with

- Flutter and Dart
- Firebase Authentication, Cloud Firestore, Cloud Storage, and Cloud Messaging
- Algolia for search

## Development setup

### Requirements

- Flutter stable with Dart SDK `>=3.0.0 <4.0.0`
- A configured Firebase project for the platforms you want to run

### Run locally

1. Install Flutter and configure the required platform toolchains.
2. Set up Firebase for the app and provide the platform configuration files required by FlutterFire.
3. Fetch dependencies and launch the app:

   ```sh
   flutter pub get
   flutter run
   ```

Run the test suite with:

```sh
flutter test
```
